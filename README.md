# Лабораторна робота №8  
## Threads — створення, управління та завершення потоків виконання

Проєкт виконано в межах лабораторної роботи №8 з теми роботи з потоками виконання в операційній системі Linux засобами мови програмування Python.

У роботі реалізовано три програмні завдання:

1. створення власного механізму блокування потоку `MyLock` на основі програмного каналу `pipe`;
2. читання файлу в окремому потоці за допомогою класу-нащадка `threading.Thread`;
3. паралельне обчислення чисел Каталана та простих чисел у двох окремих потоках.

Також у проєкті додано автоматичні тести `pytest` та перевірку стилю коду за допомогою `flake8`.

---

## Мета роботи

Метою лабораторної роботи є дослідження особливостей створення, використання та завершення потоків виконання в ОС Linux засобами Python.

Під час виконання роботи було розглянуто:

- створення потоків через модуль `threading`;
- створення власних класів-нащадків від `threading.Thread`;
- очікування завершення потоків за допомогою методу `join()`;
- передавання результатів із додаткових потоків в основний потік;
- використання системного виклику `pipe`;
- організацію I/O-bound та processor-bound задач;
- обробку параметрів командного рядка через `argparse`;
- тестування програмних рішень засобами `pytest`.

## Опис основних файлів

### `src/task1_my_lock.py`

У цьому файлі реалізовано клас `MyLock`.

Клас працює на основі програмного каналу `pipe`, який створюється за допомогою функції `os.pipe()`.

Основна ідея роботи:

- `os.pipe()` створює два файлові дескриптори:
  - один для читання;
  - один для запису;
- потік, який викликає метод `wait()`, блокується на операції `os.read()`;
- основний потік викликає метод `release()`;
- метод `release()` записує один байт у канал;
- після цього заблокований потік розблоковується і продовжує роботу.

Таким чином, `pipe` використовується не для передавання великих даних, а як простий механізм синхронізації потоків.

---

### `src/task2_file_reader.py`

У цьому файлі реалізовано клас `FileReaderThread`, який є нащадком класу `threading.Thread`.

Клас виконує I/O-bound завдання — читання текстового файлу.

Основна логіка роботи:

1. основний потік створює об'єкт `FileReaderThread`;
2. читання файлу запускається методом `start()`;
3. основний потік очікує завершення через `join()`;
4. після завершення роботи потоку контент файлу отримується через метод `get_content()`.

Таке рішення демонструє використання потоків для операцій введення-виведення.

---

### `src/task3_calculations.py`

У цьому файлі реалізовано processor-bound завдання.

Програма створює два окремі потоки:

- `CatalanThread` — обчислює задану кількість перших чисел Каталана;
- `PrimeThread` — обчислює задану кількість перших простих чисел.

Після завершення обчислень основний потік отримує результати з об'єктів потоків і виводить їх у стандартний потік виведення.

Для чисел Каталана використовується ітеративний підхід. Це зроблено тому, що числа Каталана швидко зростають, а обчислення кожного числа окремо через факторіали було б менш раціональним.

---

### `src/main.py`

Файл `main.py` є головною точкою запуску програми.

Він містить загальний інтерфейс для запуску всіх трьох завдань через командний рядок.

Для вибору потрібного завдання використовуються підкоманди:

- `task1`;
- `task2`;
- `task3`.

## Запуск програми

### Завдання 1 — демонстрація `MyLock`

```bash
python3 -m src.main task1
```

Запуск із власною затримкою перед розблокуванням потоку:

```bash
python3 -m src.main task1 --delay 2
```

```text

Worker thread: started
Worker thread: waiting for release
Main thread: worker is blocked now
Main thread: releasing worker
Worker thread: unlocked and finished
Main thread: demo finished
```

## Особливості реалізації

У роботі було використано декілька важливих механізмів Python та Linux.

### Потоки виконання

Модуль `threading` дозволяє створювати окремі потоки всередині одного процесу.  
У цій лабораторній роботі потоки використовуються для демонстрації паралельного виконання задач.

### Pipe

`pipe` — це програмний канал, який дозволяє передавати дані між частинами програми.  
У першому завданні `pipe` використовується як механізм блокування та розблокування потоку.

### I/O-bound задача

Читання файлу є прикладом I/O-bound задачі, тому що основний час виконання пов'язаний з операціями введення-виведення.

### Processor-bound задача

Обчислення чисел Каталана та простих чисел є processor-bound задачами, тому що вони залежать від обчислювальної потужності процесора.

### Argparse

Модуль `argparse` використовується для зручної передачі параметрів у програму через командний рядок.
